# Example data

`ultrachat_200k_test_sft_40.jsonl` holds the first 40 rows of the `test_sft`
split of [HuggingFaceH4/ultrachat_200k](https://huggingface.co/datasets/HuggingFaceH4/ultrachat_200k)
(dataset revision `8049631c405ae6576f93f445c6b8166f76f5505a`), fetched through the
Hugging Face datasets-server `rows` API and stored unchanged, one row per line.
UltraChat 200k is a filtered version of UltraChat (Ding et al., 2023,
<https://github.com/thunlp/UltraChat>).
